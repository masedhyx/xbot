Pengaturan API

Isi API key Gemini dan/atau Groq. Jika satu model atau penyedia error (kuota habis, model tidak cocok), bot otomatis pindah ke model berikutnya. Ketuk titik bulat di samping tiap key untuk mengetes. Kunci hanya disimpan di browser Anda.

Mode model

Otomatis memakai semua model dan pindah sendiri kalau ada yang error. Manual hanya memakai Groq dengan tingkat penalaran pilihanmu.

OtomatisGemini + Groq, pindah model otomatis saat error
ManualGroq saja (perlu API key Groq)
Tingkat penalaran
LambatBerpikir paling dalam, jawaban lebih lama
SedangSeimbang antara kualitas dan kecepatan
CepatPenalaran singkat, jawaban paling cepat
